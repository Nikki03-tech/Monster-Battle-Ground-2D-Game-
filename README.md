# Monster Battle Ground

![JavaScript](https://img.shields.io/badge/JavaScript-ES6%2B-F7DF1E?logo=javascript&logoColor=black)
![HTML5](https://img.shields.io/badge/HTML5-Canvas-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-styling-1572B6?logo=css3&logoColor=white)

A browser-based 2D side-scrolling shooter project with a landing page, account-form screens, a welcome/menu flow, and the game itself.

> **Project note:** The game engine was built while following a tutorial; the surrounding landing and page-flow work was developed as part of my learning. See Credits for attribution.

## Project Pages

The repository is organised into separate folders for the site's different screens:

- `home/` — landing page
- `signup/` — signup screen
- `login/` — login screen
- `welcome/` — welcome/start menu
- `game/` — gameplay files
- `persistent-player/` — persistent-player related files
- `audio/` — audio assets
- `Screenshots/` — project screenshots
- `index.html` — redirects to the homepage

## Gameplay Highlights

- 2D side-scrolling shooter gameplay using browser technologies
- Player movement and shooting controls
- Enemies, collision handling, scoring, and a timed round
- Win/lose state and replay/home navigation
- On-screen controls intended to help users play on touch devices

Exact controls and browser behaviour may vary as the project evolves.

## Tech Stack

- JavaScript (ES6+)
- HTML5 and CSS3
- HTML5 Canvas API

No framework build step is required for the static pages.

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Nikki03-tech/Monster-Battle-Ground-2D-Game-.git
   cd Monster-Battle-Ground-2D-Game-
   ```
2. Open `index.html` with a local static server such as the VS Code Live Server extension.
3. The homepage should open from `home/index.html`; use the page navigation to reach the other screens.

## Important Authentication Note

The signup and login pages are front-end screens. Do not use real passwords or sensitive personal information unless a secure backend authentication system has been implemented and verified.
